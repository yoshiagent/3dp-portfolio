FreeCAD

參數化 3D 建模（主力）
官方網站 ↗

開源的參數化 CAD（Computer-Aided Design）。TT 馬達系列、電池盒、麵包板底座、差速器曲柄都用它建模，FCStd 就是它的檔案格式。

本機版本
1.1.4
安裝位置
%LOCALAPPDATA%\Programs\FreeCAD 1.1（只安裝給目前使用者）

本站的建模方式

  • PartDesign 工作台：一個實體（Body）由加料／減料的方塊、圓柱特徵（Feature）依序堆出來
  • 所有尺寸放在 Params 試算表（Spreadsheet）：A 欄中文說明、B 欄數值或公式並設別名，每個特徵用運算式（Expression）綁定，改一格就整個模型更新
  • 重複的孔用 LinearPattern（線性陣列）；1.1 版一個陣列就能做兩個方向的格子

用腳本建模

  • freecadcmd.exe：不開視窗的命令列版本，執行 Python 建模腳本、存 FCStd、匯出 STEP／STL
  • 命令列存的檔沒有顯示狀態與縮圖，所以再用 freecad.exe 開一次重存（gui_finish.py），本站預覽圖也是這樣在介面裡繪製
  • 內建獨立的 Python 3.11.14（含 matplotlib 3.10.8），用來切剖面（Part.slice）畫檢查圖

踩過的雷

  • 特徵數會拖慢開檔：麵包板底座原本約 500 個特徵，介面開檔要 75 分鐘；改用陣列降到 54 個後，三個檔案合計 1 分鐘內
  • 陣列只會複製原始特徵裡第一個實體；兩個不相連的孔要各自做一個陣列，而且陣列要緊接在它的原始特徵後面
  • 兩個圓柱面剛好相切（只碰在一條線上）時，匯出的網格會有破邊；讓它們重疊 0.02 mm 就正常
  • 3MF 用 Mesh.export（等同介面的「匯出」）產生，匯出後檢查是否為封閉實體

OpenSCAD

程式碼式 3D 建模
官方網站 ↗

用文字程式碼描述形狀的 CAD，適合尺寸規則、靠參數變化的零件。LEGO × DUPLO 轉接磚和行星齒輪教學模型的 .scad 原始檔都用它開啟。

本機版本
2021.01
安裝位置
C:\Program Files\OpenSCAD

本站的用法

  • 參數集中放在檔案開頭，並用 /* [LEGO 底部] */ 這類註解分組，在自訂器（Customizer）面板裡直接調整
  • 行星齒輪檔用一個 part 變數切換要輸出的零件（sun、planet、ring…），按 F6 算繪後匯出 STL
  • 漸開線齒形、齒數、背隙等都寫成參數，改一個數字就能重出整組齒輪

注意

  • 2021.01 是較舊的穩定版，大型布林運算較慢
  • 轉接磚最早期本機還沒有 OpenSCAD，STL 改用 Python manifold3d 依同一組參數產生（build_stl.py）

用在這些作品（2 件）

  • 行星齒輪教學模型
  • LEGO × DUPLO 轉接磚

Bambu Studio

切片軟體（Slicer）
官方網站 ↗

Bambu Lab 官方切片軟體，把 3D 模型切成印表機要走的路徑（G-code）。本站大部分 3MF 都是它的專案檔，連同切片設定與列印盤一起保存。

本機版本
02.09.01.70
安裝位置
C:\Program Files\Bambu Studio

本站的用法

  • 印表機：Bambu Lab X2D 雙噴頭——左噴頭直驅印模型，右噴頭遠端送料專印支撐材
  • 耗材分組改成手動，避免自動分組把模型和支撐材的噴頭對調
  • 一個 3MF 專案可以有多個列印盤（例如差速器、行星齒輪 v2 各 2 盤）
  • 3MF 內建每個列印盤的預覽圖，本站作品卡片的部分圖片就是從裡面取出

試尺寸的設定

  • 量配合尺寸（凸點、十字孔）時，X-Y 輪廓補償設 0，否則量到的不是模型本身的尺寸
  • 同一盤印多個不同尺寸的試件，一次挑出最合適的（DUPLO 凸點 9.55 mm、十字孔間隙都是這樣定的；十字孔後來實印發現太緊，再放鬆到 0.15 mm）

用在這些作品（7 件）

  • 電動差速器教學模型
  • TT 馬達 20:1 減速器（參考原件）
  • Hello Kitty Mini 鑰匙圈改裝
  • 開放式差速器教學模型
  • 行星齒輪教學模型
  • 一體成形行星齒輪（試印）
  • LEGO × DUPLO 轉接磚

Python ＋ manifold3d

腳本、網格運算、檢查圖
官方網站 ↗

用來寫各種小工具：產生 STL、直接修改 3MF、畫剖面檢查圖，以及產生這個網站。

本機版本
Python 3.12.10、manifold3d 3.5.4
安裝位置
%LOCALAPPDATA%\Programs\Python\Python312

裝了哪些套件

  • manifold3d 3.5.4：快速、可靠的網格布林運算（聯集、差集），輸出一定是封閉實體
  • numpy 2.2.6：網格頂點與座標運算
  • matplotlib 3.10.9：畫剖面與檢查圖

用在哪裡

  • build_stl.py：依 .scad 相同參數產生 LEGO × DUPLO 轉接磚 STL
  • add_keyring.py：讀進 3MF、在公仔頭頂加鑰匙圈環、寫出新的 3MF
  • tools/build_site.py：讀作品目錄，產生本網站所有頁面
  • linkage.py：MG90S 轉向的四連桿解算與阿克曼幾何最佳化

用在這些作品（4 件）

  • 差速轉向車模型（電動差速器＋MG90S 轉向）
  • MG90S 伺服機前輪轉向機構（阿克曼）
  • Hello Kitty Mini 鑰匙圈改裝
  • LEGO × DUPLO 轉接磚

build123d（text-to-cad 外掛環境）

Python 參數化 CAD（齒輪等複雜幾何）
官方網站 ↗

以 OpenCascade 核心為基礎的 Python CAD 函式庫，能直接做出 B-rep 實體並匯出 STEP。齒形計算這類需要大量數學的零件用它最方便。

本機版本
隨外掛提供
安裝位置
Claude Code 的 text-to-cad 外掛（cadgen 執行環境，%LOCALAPPDATA%\cadgen）

本站的用法

  • 差速器的所有零件：直齒傘齒輪用 Tredgold 近似，漸開線齒形放樣到錐頂，再做變位避免根切
  • 行星齒輪 v2／v2.1 的零件與組裝模型，用來做試裝檢查（Fit Check），並和 .scad 保持同步
  • 差速器動畫用的網格也是從這個環境匯出（export_meshes.py），再放進 Three.js 網頁
  • 電動差速器：匯入 FreeCAD 做好的馬達外框、電池盒、麵包板 STEP，組成整台模型，再跑干涉與齒輪嚙合檢查
  • MG90S 轉向機構：依連桿解算結果擺出各個轉向角度，掃描整個轉向範圍檢查零件干涉
  • 差速轉向車：整車底盤、Ø80 後輪與平台建模，組合兩個模組後檢查干涉、轉向掃掠、齒輪嚙合與 140 個插銷孔

注意

  • 它跑在外掛自己的 Python 裡，不在系統 Python 的套件清單中；腳本要用該環境的 python 執行

用在這些作品（5 件）
